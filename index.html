Google Sheets

Connect your own sheet using the included Apps Script. Orders and status changes sync with an acknowledgement; pending records stay saved for retry.

  1. Open a Google Sheet → Extensions → Apps Script.
  2. Paste google-sheets.gs. Set the sheet ID and a private sync key.
  3. Deploy as a Web app: execute as yourself, access “Anyone”.
  4. Paste the deployment URL and matching key below.

The key is stored on this device. Use this POS only on trusted staff devices. A connection is required before live Sheets logging works.
